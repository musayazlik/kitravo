# Changelog

## 1.0.0 — 2026-10-19

- Introduced the Kitravo brand, shared logo, and application icons.
- Added the interactive public landing page, multilingual blog, and protected content workspace.
- Made English the default interface and documentation language while retaining five optional locales and Arabic RTL support.
- Implemented durable authentication, read-only demo sessions, permission-based roles, multiple role assignments, and audit history.
- Added PostgreSQL support for Vercel deployments while retaining SQLite for local development.
- Corrected landing dark-mode surfaces, cover contrast, and reduced-motion hydration.
- Added release documentation, CI checks, and deployment configuration for `kitravo.musayazlik.com`.

Content-provider, AI, MCP execution, uploads, and outbound-email integrations remain extension points; content screens use typed sample data.
